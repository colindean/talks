# Homebrew on Linux submissions

## Open Source North

### Presentation summary

Representing Homebrew for the last few years at FOSDEM— the largest open source developer conference in Europe— has taught me that Homebrew's availability on Linux isn't widely known. Homebrew is _The Missing Package Manager for macOS (or Linux)_. The _(or Linux)_ part has been around for several years. The project expanded support in 2025 to include Linux on ARM CPUs. I'll explain the major use cases for Homebrew on Linux, including my own for the last 6+ years, I'll review some history, and I'll explain what excites me about the future of Homebrew on next-generation Linux OSes like Bluefin for developers and Bazzite for gamers.
