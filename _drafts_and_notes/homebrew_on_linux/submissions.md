# Homebrew on Linux submissions

## FOSDEM 2026

_([submission](https://pretalx.fosdem.org/fosdem-2026/talk/review/M8KPAETEKENUP8EYWRUUV8Y7PATZVYKA))_

Homebrew is _The Missing Package Manager for macOS (or Linux)_. The _(or Linux)_ part has been around for many years. Over the last few years, I chatted with folks at FOSDEM and learned that Homebrew's availability and utility on Linux aren't widely known. The project expanded support in 2025 to include Linux on ARM CPUs. I'll explain the major use cases for Homebrew on Linux, including my own for the last 6+ years, I'll review some history, and I'll explain what excites me about the future of Homebrew on next-generation Linux OSes like Bluefin for developers and Bazzite for gamers.
